# QR Campaign

Dynamic QR codes and short links with analytics, routing rules and your own domain.

[QR Campaign](https://qr-campaign.com/) lets you print a QR code once and change where it points
afterwards, without reprinting. Every code and short link has scan analytics, and can be protected
with a password, an expiry date, or routing rules by country, device or time.

## Free tools

Run in your browser, no sign-up.

- [QR code generators](https://qr-campaign.com/qr-code-generator/): free static codes for URLs, Wi-Fi, text, email, phone, SMS and more
- [UTM builder](https://qr-campaign.com/free-tools/utm-builder/): tag campaign links consistently
- [Bulk UTM builder](https://qr-campaign.com/free-tools/bulk-utm-builder/): tag many links at once
- [URL parser](https://qr-campaign.com/free-tools/url-parser/): see what a link contains before you edit it
